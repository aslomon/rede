rede 1.1 bringt zwei optionale Online-Funktionen, neuere Modelle und Updates über GitHub.

  • live-text (optional, aus): beim Sprechen erscheint der Text schon in der Pille. Dafür geht dein Audio an OpenAI und du brauchst einen OpenAI-Key; gesendetes Audio lässt sich nicht zurückholen. Im sicheren Lokalmodus bleibt Live aus. Klappt Live nicht, transkribiert rede danach wie bisher.
  • automatik (optional, aus): rede kann erkennen, ob du eine E-Mail oder einen Prompt für eine KI diktierst, und das Umschreiben darauf abstimmen. Dafür gehen der diktierte Text, der Name der aktiven App und – falls der Modus sie ohnehin nutzt – ausgewählter Text oder Text aus dem aktuellen Feld an OpenAI. Du schaltest sie pro Modus ein; in Passwortfeldern und im Lokalmodus läuft sie nicht.
  • modelle: neue Einträge im lokalen Modellkatalog; sie sind als „nicht lokal geprüft“ markiert und laden erst, wenn du auf „laden“ drückst. Neue Umschreib-Modi nutzen GPT-6 Luna, mit einstellbarem Denkaufwand. Bereits gespeicherte Modi und Modelle bleiben, wie sie sind.
  • updates: rede holt Updates wieder über GitHub. Jedes Update ist signiert und wird vor der Installation geprüft. Unter System → Updates schaltest du die tägliche Prüfung und das automatische Laden ein oder aus; eine Installation wartet, bis dein Diktat fertig ist.
